PLANK Host is installed

Open PLANK Host in Applications to review and grant macOS privacy permissions.

Screen recording, Accessibility and input permissions are managed in System Settings → Privacy & Security. Audio consent is requested when desktop audio capture starts.

Startup is configured for the login screen and desktop. No reboot is required.

To uninstall, run the included script in Terminal:

sudo "/Applications/PLANK Host.app/Contents/Resources/uninstall.sh"

Configuration, certificates, logs and privacy permissions are retained. No separate download is needed.
