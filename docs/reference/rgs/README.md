# RGS Toolbar References

These user-supplied screenshots are visual references for StationConnect's
in-stream toolbar. They illustrate the recognizable upright pushpin silhouette
and the compact organization of an established remote-workstation toolbar.
StationConnect does not need to reproduce the RGS layout exactly.

- `toolbar-overview.png` — low-resolution RGS toolbar overview.
- `toolbar-pin.png` — close-up of the RGS pushpin icon.
