# PLANK 1.0.147 candidate

## Host and Client

- Preserve valid maximum-sized transport packets during MTU-loss recovery.
  An incorrect boundary comparison could discard queued video data and cause
  a skipped frame. The shared transport fix applies across platforms.
- Distinguish genuine MTU-related packet discards from full send-queue drops
  in transport diagnostics.

This candidate retains the 1.0.146 changelog and macOS listener-recovery work.
It does not change encoder settings, FEC, negotiated MTU, queue capacities,
reordering delay, or the accepted fast-send policy.

Regression coverage includes exact packet-size boundaries, queue accounting,
and repeated 150 Mbps progressive-loss tests. The test proxy reports unintended
local socket drops separately; all original frame and FEC assertions remain.
See HANDOFF.md for build status and validation limitations. No live hardware
acceptance or release publication is implied by this candidate.
