# PLANK 1.0.120

Mainline release of Linux and macOS Host/Client packages. Changes below are
relative to macOS Host 1.0.106 and Client 1.0.105.

## macOS display and fullscreen

- Native fullscreen Spaces support restores trackpad gestures for switching
  between fullscreen applications.
- Fullscreen Match Client uses the current display's logical size, backing-pixel
  density and camera safe area. Retina displays retain their 2x desktop scale;
  ordinary 1x displays remain 1x. This prevents tiny remote UI and unnecessary
  side borders without stretching the video.
- Notched displays retain the system-owned top safe area so remote menus are
  not obscured. Displays without a camera inset retain their full usable area.
- Mac Hosts accept exact dynamically requested desktop dimensions rather than
  restricting Match Client to a predefined resolution list.
- Authenticated display preparation wakes the desktop and waits boundedly for
  usable geometry. Real remote input reports console activity, addressing
  native login-screen password rejection while the console is inactive.

Use matching 1.0.120 Host and Client packages for the updated Mac display
negotiation. Start a fresh fullscreen connection to apply Match Client sizing;
toggling window mode does not renegotiate an existing remote desktop.

## Authentication and reconnect

- Abandoned macOS authentication setups no longer unnecessarily occupy setup
  capacity. Successful authentication clears failure backoff; diagnostics
  distinguish credential rejection from backend errors without logging secrets.
- Temporary authenticated display/topology readiness retries retain their
  setup authorization within its original expiry. Cancellation, rejection,
  ownership change or failed launch still revoke it.
- Client reconnect attempts respect the configured Ask/Disconnect deadline.
  Keep Waiting explicitly resumes attempts; definitive authentication, TLS
  and permission failures stop instead of repeatedly submitting credentials.
- A connection completing after its deadline is discarded rather than left
  hidden behind an unanswered prompt.

Linux Host and transport source revisions are unchanged; their existing
encoding, color, input and network behavior is retained.

All four packages were cold-bootstrapped and rebuilt from mainline commit
`53c7c3988f88a440f1cffeda0ce61ed526de6c43`, identified by the release tag:

- [Linux Host build](https://github.com/instinctual/plank/actions/runs/35137573043)
- [Ubuntu Client build](https://github.com/instinctual/plank/actions/runs/35137572752)
- [macOS Host build](https://github.com/instinctual/plank/actions/runs/35137572797)
- [macOS Client build](https://github.com/instinctual/plank/actions/runs/35137572549)

Build, dependency-patch, version and uninstalled package gates passed. Both Mac
packages passed Developer ID signing, notarization, stapling and Gatekeeper.
The fullscreen candidate received operator acceptance. Fresh live tests of
these exact release artifacts and exhaustive recovery/display combinations
were not performed; package checks do not replace hardware acceptance.

`SHA256SUMS` uses release-asset filenames. `manifest.json` records exact source,
dependency revisions and validation states using platform-organized local
catalog paths. The subsequent dependency-cache work is not part of this release.

GitHub source archives omit submodules. Obtain complete matching source with:

```sh
git clone --recurse-submodules --branch v1.0.120 https://github.com/instinctual/plank.git
```
