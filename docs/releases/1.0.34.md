# PLANK 1.0.34

Mainline package build of the accepted 1.0.33 session-lifecycle changes.
The Host and Client runtime source is unchanged from the accepted feature
candidate; all packages use version 1.0.34 without a branch suffix.

## Changes

- Root supervisor delegates a connected PAM broker descriptor to the media
  worker. Credentials travel directly between the worker and PAM broker,
  not through the supervisor; broker permissions remain root-only.
- Fatal X11 connection loss retires the worker without NVIDIA exit-handler
  deadlock. Closed worker-control descriptors no longer cause repeated
  malformed-request logs.
- Encoder startup rejects ineligible probe combinations before capture
  acquisition, retaining real tests for supported formats.
- Login and logout progress is displayed on a local Wayland surface even
  when decoded video is paused.
- A bounded, credential-free, certificate-pinned worker-replacement check
  avoids waiting for the old transport to expire after desktop replacement.
  Reconnection still requires PAM authentication and desktop ownership.

The media worker still runs as root. Descriptor delegation is groundwork for
privilege separation, not completion of an unprivileged-worker design.

## Packages and qualification

The user's acceptance of 1.0.33 covers the observed login/logout result.
Fresh package build checks do not substitute for hardware qualification of
these exact 1.0.34 artifacts or the remaining outage/Wait/Disconnect tests.
See HANDOFF.md for build results, exact provenance and package SHA-256 values.

This build request does not deploy packages, create tags, or publish a GitHub
release. Artifacts are retained in artifacts/packages/ with SHA-256 sidecars.
