# PLANK 1.0.105

Full mainline rebuild of the public Linux and macOS Host/Client packages.
Changes below are relative to release 1.0.103; the macOS Host fixes were also
provided in the accepted 1.0.104 candidate and subsequent mainline installer.

## Fixes

- macOS Host: recover an inactive, PLANK-owned virtual display when an
  authenticated connection cannot read its topology. Recovery retains the last
  successful resolution, is bounded and ownership-checked, and does not change
  physical monitor modes or create duplicate displays.
- macOS Host installer: fix owner-only application resources that could produce
  a prohibited icon or a "damaged or incomplete" launch error for ordinary
  users. Public app bundle permissions are now checked in the assembled app,
  staged payload and finished installer. Private keys and installed private
  state retain their restricted permissions.

## Build and distribution

- Clean, pinned-source GitHub-hosted builds for all four platform/product
  combinations, with source revision and dependency-patch checks.
- Protected macOS Developer ID signing and notarization on disposable runners,
  with temporary-keychain cleanup. Explicitly requested signed builds on allowed
  branches proceed without a separate approval prompt; public pull-request
  builds do not receive signing credentials.
- Updated CI actions for Node.js 24 and expanded installation/configuration
  documentation.
- No Linux Host, shared Client or transport dependency revisions changed from
  1.0.103. Those packages are rebuilt at the common release version, not relabeled.

## Packages and requirements

| Product | Platform | Package |
| --- | --- | --- |
| Host | Rocky Linux 9.7, x86-64 | RPM |
| Client | Ubuntu 26.04, x86-64 | DEB |
| Host | macOS 27, Apple Silicon | Signed/notarized PKG |
| Client | macOS 27, Apple Silicon | Signed/notarized DMG |

macOS support remains experimental and requires macOS 27. Existing permissions
and platform setup requirements still apply. See `docs/README.md` and
`docs/development/acceptance-criteria.md` for remaining hardware qualification
gates. No automatic installation or workstation configuration change is part
of publishing this release.

## Verification and source

The release assets include `SHA256SUMS` and `manifest.json`. The checksum file
uses release-asset filenames; the manifest records exact build commits,
dependency revisions, target platforms and package checks using the local
platform-organized catalog paths. Build/package checks do not substitute for
live display, audio, input or hardware-decoder acceptance.

GitHub source archives omit submodules. Obtain complete matching source with:

```sh
git clone --recurse-submodules --branch v1.0.105 https://github.com/instinctual/plank.git
```
