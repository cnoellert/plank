# PLANK 1.0.121

Mainline Host/Client package rebuild following 1.0.120.

## Changes

- The macOS Client forwards native application Quit requests to the active SDL
  streaming loop so it can follow the existing disconnect and resource-cleanup
  path before application exit. This includes Client PR #1 at merge commit
  `b9e4be6b374001bef08ac4753764bc12edcb8357`.
- All four hosted build paths can reuse exact-input, independently verified
  dependency caches. Application builds, tests, packaging and signing remain
  fresh; credentials and application objects are not cached.

Linux runtime behavior, Host implementations and transport are unchanged.
Clipboard synchronization remains under review and is not included.

## Validation scope

Native Quit is not a new Command-Q binding. The bridge handles application Quit
events after Qt receives them; physical shortcut ownership under the selected
keyboard-capture policy still needs native macOS verification. Menu/Dock Quit
during streaming and reconnect also remains a live acceptance follow-up.

All four hosted builds passed from mainline source
`41961fb5e9ef8329711e04d1adf75cc4b2968ce3`:

- [Linux Host](https://github.com/instinctual/plank/actions/runs/35166761486)
- [Ubuntu Client](https://github.com/instinctual/plank/actions/runs/35166763396)
- [macOS Host](https://github.com/instinctual/plank/actions/runs/35166765361)
- [macOS Client](https://github.com/instinctual/plank/actions/runs/35166767426)

Both Clients and the macOS Host restored and verified dependency caches. The
Linux Host rebuilt dependencies because NVIDIA's repository changed
`cuda-toolkit-13-config-common` and `cuda-toolkit-config-common` from
13.4.49 to 13.4.92; installed package versions are exact cache-key inputs.
The successful Linux Host build saved the new cache. Application compilation
and packaging were fresh for every product. Both Mac packages passed signing,
notarization, stapling and Gatekeeper checks. All four downloaded packages
passed SHA256 verification and were collected with source provenance under
`artifacts/packages/releases/1.0.121/`.

Successful build checks are not live runtime acceptance. macOS support targets
macOS 27+ on Apple Silicon and remains subject to the existing release gates.
No installation or workstation configuration change is part of this rebuild.
