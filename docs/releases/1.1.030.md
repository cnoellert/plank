# PLANK 1.1.030

Changes since [1.0.143](https://github.com/instinctual/plank/releases/tag/v1.0.143),
the previous published release.

**Upgrade Host and Client together.** Network loss recovery now uses RaptorQ 2;
its recovery format is incompatible with 1.0.143.

## Client

- Improve sustained audio synchronization with Mac Hosts using Host timestamps and smooth resampling. Protect playback from excessive catch-up when the output device needs more data.
- Restore video-clock tracking on the Linux hardware-rendering path.
- Forward your microphone from Linux or macOS to a Mac Host, with a toolbar mute control. New configurations start muted.
- Forward supported webcams from Ubuntu to a Mac Host. Camera forwarding starts off.
- Show **In Session** status, with an optional username when the Host administrator allows it.
- Optionally remember the last successful bookmark username; never save passwords.
- Take over your active Mac session from another Client, including when the Mac is locked.
- Remember Host identities and ask before accepting a changed identity.
- Install the Mac Client with a PKG, permission setup and an uninstaller.
- Improve connection cancellation, shutdown and Wacom recovery after switching apps or Spaces.
- Read the built-in changelog by clicking the version number.

## Host

- macOS: add **PLANK Microphone** and **PLANK Camera** for remote application input.
- macOS: route remote audio through **PLANK Output**, with volume and mute support and restoration after disconnect.
- macOS: improve login-screen transitions, session takeover and recovery after startup or user changes.
- macOS: document administrator settings in `/etc/plank/host.conf` and simplify permission setup and optional-device removal.
- Linux: improve virtual-monitor ordering and release held tablet contact when forwarding pauses, without recreating the tablet.
- Linux: bound operating-system authentication checks so a stalled backend does not indefinitely block other authentication requests.
- Both platforms: upgrade network loss recovery and harden malformed-data handling, cancellation and queue overflow.

## Validation notes

The audio changes have automated finite-queue, resampling and clock-drift tests.
A long real-world listening test of the latest playback guard and measured
absolute A/V synchronization remain pending. Existing hardware qualification
requirements, including the latest Wacom lifecycle changes, still apply.
