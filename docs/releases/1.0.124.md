# PLANK 1.0.124

## Changes

- Fix macOS Command-Q quitting both the remote application and PLANK. With
  keyboard capture active and the stream focused, Command-Q belongs only to
  the remote session. Local shortcut behavior returns when capture is released.
- Replace the macOS Quit bridge with explicit application-exit ownership.
  Menu/Dock Quit cancels startup or an active/reconnecting session and waits
  for resource cleanup before exiting. Ordinary Disconnect keeps PLANK open.
- Add native shortcut and application-lifecycle regression tests to every
  macOS Client build, including repeated Quit and overlapping cleanup.

Linux runtime behavior, Host implementations and transport are unchanged.
Clipboard synchronization PRs remain under review and are not included.

## Packages

- Linux Host: Rocky Linux 9.7, x86-64 RPM.
- Linux Client: Ubuntu 26.04, x86-64 DEB.
- macOS Host: macOS 27+, Apple Silicon, signed/notarized PKG.
- macOS Client: macOS 27+, Apple Silicon, signed/notarized DMG.

All packages are rebuilt from main, not renamed candidate artifacts.
`SHA256SUMS` uses downloadable asset filenames. `manifest.json` records exact
source revisions and package validation using platform-organized catalog paths.
GitHub source archives omit submodules; use a complete source clone:

```sh
git clone --recurse-submodules --branch v1.0.124 https://github.com/instinctual/plank.git
```
