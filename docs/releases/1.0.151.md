# PLANK 1.0.151

## Client

- Ask before taking over an active Mac session belonging to the same account,
  including while the desktop is locked.
- Keep Take Over and Cancel responsive, use the replacement client's display
  size, and prevent the displaced client from automatically taking it back.
- Preserve valid full-sized packets during network packet-size recovery.
- Ubuntu: install the Qt image plugin needed to display dialog icons.

## Host

- macOS: transfer an active session only with explicit same-account consent,
  releasing the old client's input and media before changing the display.
- macOS: fix control-socket cleanup between the login screen and desktop to
  avoid a temporary loss of connectivity during login or logout.
- Linux and macOS: preserve valid packets during packet-size recovery and move
  diagnostic logging outside the transport connection lock.
- macOS: leave detailed frame tracing off unless explicitly enabled for diagnosis.

## Build and qualification

- Cache dependencies independently and save verified caches before application
  tests, so later build failures do not discard successful dependency preparation.
- Strengthen packet-loss tests with throughput, delivery-delay and recovery
  requirements, alongside byte-for-byte recovery checks.
- Add real cross-user TLS listener handoff tests and a negative control that
  reproduces the old port-conflict failure.

This mainline rebuild incorporates the combined 1.0.147–1.0.150 candidates.
Build/package results and outstanding live hardware gates are recorded in
HANDOFF. Package generation does not publish a GitHub release or install it.
