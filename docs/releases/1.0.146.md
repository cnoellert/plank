# PLANK 1.0.146 unified test build

## Client

- Click the version number in the main window to open the bundled changelog.
  Short release highlights are grouped into Client and Host sections and work
  offline. The dialog supports scrolling, keyboard navigation and Close/Escape.

## Host

- macOS: retry desktop-service startup when an admitted worker exits after
  login or user switching. The existing coordinator releases the old worker's
  lease before retrying, uses bounded backoff, and discards stale retries.
- Record numeric listener failure details in the macOS product log.

System-keyboard capture settings and their Accessibility behavior are unchanged.
Linux Host runtime, transport, encoding profiles and dependency pins are unchanged
from 1.0.143. This build combines the separately validated changelog and listener
recovery branches; it does not include unrelated pending work.

## Packages and validation

Matching 1.0.146 packages are being rebuilt from main on GitHub-hosted builders:
Rocky Linux 9.7 Host RPM, Ubuntu 26.04 Client DEB, macOS 27+ Apple Silicon Host
PKG, and macOS 15+ Apple Silicon Client DMG. Mac distribution packages require
Developer ID signing, notarization and stapling. Existing exact-input dependency
caches may be reused; application/transport compilation and package gates run
fresh. Nothing is automatically installed or published as a GitHub release.

The separate feature builds passed Client dialog/input/package tests and Mac
Host recovery, authentication and session-lifecycle tests. Combined-build results
and exact package provenance will be recorded in HANDOFF.md and the artifact
manifest. Compile/package success is not live recovery acceptance.

## Requested live checks

1. Install the matching Host and Client. Click the Client's version number and
   verify the 1.0.146 notes have both Client and Host sections.
2. Check normal login, logout and reconnect.
3. Reproduce PLANK authorization as one account followed by macOS login as a
   different account. The Host should remain reachable or recover without a
   manual service restart. Access to the different desktop must still require
   fresh authorization as its owner; no token transfers between users.

Retries are finite, not an unlimited restart loop. Wallpaper/Screen Saver
settings hover lag remains deferred. Existing permission, screen-lock, Wacom,
exact-color, network, clipboard immediate-paste, macOS 15/27 Client and long-session
acceptance gates still apply. The Linux physical-display provenance issue is
unchanged. See docs/development/acceptance-criteria.md.
