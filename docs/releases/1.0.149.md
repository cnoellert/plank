# 1.0.149 candidate

This unmerged candidate combines the macOS session-takeover repair with the
1.0.147 MTU-boundary correction and all 1.0.148 review-hardening changes.

## Client

- Ask before replacing an active Mac session belonging to the same account.
- Keep Take Over and Cancel responsive and use the replacement client's
  display size before decoder initialization.
- Stop automatic reconnection when another client owns the stream.
- Keep legal full-sized datagrams during MTU recovery.
- Ubuntu: explicitly install the Qt SVG plugin needed to display dialog icons.

## Host

- macOS: explicitly transfer an active stream, including at the lock screen,
  without logging out the desktop user or allowing another account to take it.
- Release the displaced client's input and drain capture/transport before
  changing the display. Reserve the next launch briefly for the approved client.
- Retain the shared MTU correction, opt-in detailed Mac capture tracing and
  bounded asynchronous QUIC telemetry logging.

## Build and validation

Independent dependency caches and strict 150 Mbps packet-loss performance
gates are retained. Verified dependencies are now saved before product tests,
so a later build failure does not discard a successful dependency bootstrap.
Signing credentials remain outside dependency preparation and caches.
Matching Host and Client are required for the Mac takeover
feature. Linux session-takeover behavior is unchanged. Compilation, packaging
and live acceptance results are recorded separately in HANDOFF; this document
does not imply that an unfinished candidate is ready to install.
