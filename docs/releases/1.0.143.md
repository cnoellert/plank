# PLANK 1.0.143

## Changes since 1.0.137

- Correct absolute mouse coordinates at the right and bottom image edges in
  both the Client and shared input sender. Prevent valid edge interaction from
  becoming an out-of-bounds packet that the macOS Host rejects. Preserve ordered
  button/key events and strict Host validation.
- Remove the Linux Host's inherited delayed-left-release/synthetic-right-click
  workaround. Deliver buttons immediately and retain disconnect/session cleanup.
- Apply the fast-send policy to Linux Host: remove application datagram pacing
  and use the same 1 Gbps minimum rate-derived Quinn window budget as macOS.
  This does not set the encoder bitrate to 1 Gbps or change FEC, MTU or queue sizes.
- Stop treating macOS screen-lock notification alone as permanent revocation
  of an authenticated graphical session. Logout, user switching, sleep, changed
  console ownership, permission loss and expired admission remain protected;
  the macOS lock screen still requires normal OS authentication.
- Allow administrators to read macOS system Host logs without granting write
  access. Private user logs, credentials and keys retain their protections.
- Add privacy-safe session-stop/transport-failure classification and bounded
  input timing summaries, with new lifecycle, input-boundary and package tests.

The operator accepted these changes after candidate testing and reported no
further waiting popup during the latest observation. Versions 1.0.138–1.0.142
were integration candidates; 1.0.143 is the fresh mainline rebuild.

## Packages

- Linux Host: Rocky Linux 9.7, x86-64 RPM.
- Linux Client: Ubuntu 26.04, x86-64 DEB.
- macOS Host: macOS 27+, Apple Silicon, signed/notarized PKG.
- macOS Client: macOS 15+, Apple Silicon, signed/notarized DMG.

All products are rebuilt on GitHub-hosted builders from main. Exact-input
dependency caches may be reused; application/transport compilation and packaging
run fresh. No machine is automatically upgraded. NVIDIA driver qualification
remains capped at 595.91.07.

`SHA256SUMS` uses downloadable filenames; `manifest.json` records package-source
commits, dependency pins and validation separately from live acceptance.
GitHub source archives omit submodules; clone the complete release with:

```sh
git clone --recurse-submodules --branch v1.0.143 https://github.com/instinctual/plank.git
```

## Validation and known limitations

Mainline build and signing results will be recorded before publication.
Candidate tests passed Client input-boundary suites, Mac lifecycle/session
tests, native log-access checks, Linux input cleanup and fast-send/baseline
transport tests. Hardware-dependent UHID skips are not hardware acceptance.

Mouse lag over macOS System Settings' Wallpaper and Screen Saver panels remains
unresolved and is explicitly deferred. It is distinct from actual screen-lock
handling; this release does not claim to fix it or every possible reconnect.
Synthetic lock/authority tests do not replace live lock/unlock and user-switch
qualification. Broader permission, Wacom, color, network and long-session gates
still apply.

The existing Linux physical-display lease/provenance mismatch and clipboard
immediate-paste stress gate remain open. macOS27 beta results require final-OS
revalidation. Unrelated pending PRs and RK3576 research are not included.
