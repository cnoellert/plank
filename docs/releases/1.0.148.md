# PLANK 1.0.148 candidate

## Host

- macOS: disable detailed frame tracing by default; retain an explicit opt-in
  for diagnostics while keeping normal capture summaries and errors.
- Move QUIC diagnostic output off the connection lock and media task. A slow
  log destination drops diagnostic samples instead of delaying transport work.

## Build and qualification

- Cache independently reusable dependencies separately, reducing unnecessary
  rebuilds after unrelated dependency changes.
- Require sustained throughput and bounded frame-delivery delay during the
  150 Mbps loss matrix, in addition to exact recovery of every frame.

This candidate retains the 1.0.147 MTU-boundary repair and previous Client
behavior. No encoder, FEC, buffer, MTU or sender-rate policy changes were made
for this candidate. The paced comparison failed the new local performance
gate; the failure is retained, not bypassed. The hosted builder subsequently
passed all six matrices without changing the limits. Consult HANDOFF.md for
the separate evidence and remaining gates. This branch is not merged or a
published release.
