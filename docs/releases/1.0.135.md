# PLANK 1.0.135

## Changes since 1.0.124

- Add macOS system-shortcut capture through the existing capture preference.
  With capture active and the stream focused, Command-Tab and Command-Space
  reach the Host; captured Command-Q behavior remains intact. Capture resumes
  after a three-finger Spaces swipe away and back, without needing a click.
  Background shortcuts remain local, and returning does not override explicit
  capture release or revoked Accessibility permission.
- Request Accessibility permission at ordinary Client startup, or when capture
  is enabled in idle Settings, rather than behind an active stream. Previously
  granted permission does not prompt again. CLI autoconnect requires prior
  authorization through the ordinary launcher.
- Add plain-text clipboard synchronization between the macOS Client and Linux
  X11 Host, with negotiated support, bounded transfers, ownership checks and
  disconnect cleanup. Both peers must be updated. Mac Host and Linux Client
  clipboard backends, files and images are not included.
- Add a compact Network RTT indicator to the toolbar, using the same measured
  value as the onscreen statistics. Resize the bitrate slider to match its
  Encoder Target segment without changing toolbar height or input routing.
- Fix a Metal overlay replacement race that could briefly omit the toolbar
  during redraws. Keep the previous complete image until its replacement is
  ready, including when allocation fails.
- Integrate macOS multi-display Metal presentation and raw-HID Wacom support,
  with fullscreen/pointer cleanup and delayed input-release recovery. One
  Apple Silicon Client package now targets macOS 15 and newer using SDK 27;
  newer APIs remain available behind runtime checks. The Mac Host still
  requires macOS 27.
- Preserve mouse-move/button ordering and release delivery under input queue
  pressure. Include the Linux virtual-HID Pause-key release correction.
- Incorporate reviewed x264 and Vulkan dependency updates, including the
  Vulkan allocation-failure repair and reproducible patch gates. Update Rustls
  to 0.23.45 and reviewed CI Actions; add dependency-maintenance checks.
  NVIDIA headers remain pinned for the existing 595.91.07 driver ceiling.

The separate Linux physical-monitor mode-change contribution and other
unmerged PRs are excluded. No application datagram pacer is restored.
1.0.134 was withheld before publication and is superseded by this release.

## Packages

- Linux Host: Rocky Linux 9.7, x86-64 RPM.
- Linux Client: Ubuntu 26.04, x86-64 DEB.
- macOS Host: macOS 27+, Apple Silicon, signed/notarized PKG.
- macOS Client: macOS 15+, Apple Silicon, signed/notarized DMG.

Release packages are rebuilt from main, not renamed branch artifacts.
`SHA256SUMS` uses downloadable asset filenames; `manifest.json` records exact
source revisions and package validation with platform-organized catalog paths.
GitHub source archives omit submodules; clone the complete release instead:

```sh
git clone --recurse-submodules --branch v1.0.135 https://github.com/instinctual/plank.git
```

Build success is not a substitute for hardware qualification. Explicit live
checks remain for startup permission timing, the final overlay repair, identical
Client-package behavior on macOS 15/27, permission-denial/revocation and
Wacom/clipboard interruption and reconnect stress. A Linux physical-display
lease inconsistency can still reject a connection with an invalid composite-
source/provenance error; this release does not claim to repair it. macOS 27 beta
results need final-OS revalidation. No deployment is included in this release
operation.
