# PLANK 1.0.137

## Changes since 1.0.135

- Add authenticated plain-text clipboard synchronization between the macOS
  Host and macOS Client. Clipboard access belongs to the active desktop session;
  it is not enabled at the login screen. Mac Client ↔ Linux X11 Host transfers
  remain supported.
- Apply a shared 512 KiB UTF-8 clipboard limit to the supported Mac/Linux
  endpoints. Reject oversized, malformed or embedded-NUL text without truncating
  it. Files, images, rich text and a Linux Client clipboard backend are not
  included.
- Resume clipboard transmission from the unsent chunk under queue pressure,
  rather than restarting the transfer or disconnecting video. Improve session
  validation and cleanup, preserving newer locally copied text. Clipboard
  contents are never logged.
- Independently verify the required Vulkan Loader allocation-failure patch
  during Linux Host dependency bootstrap, cache validation and package preflight.
  Add twelve regression cases, including precise handling of intentionally
  omitted upstream test files and Unicode filenames. The Loader repair itself
  was already included in 1.0.135; no graphics driver or dependency pin changes
  are introduced here.

The operator accepted the 1.0.136 clipboard candidate before merging. Version
1.0.136 was used for candidate validation; 1.0.137 is the new mainline release.
Upgrade Host and Client together: the macOS launch contract now explicitly
negotiates clipboard support using schema 3.

## Packages

- Linux Host: Rocky Linux 9.7, x86-64 RPM.
- Linux Client: Ubuntu 26.04, x86-64 DEB.
- macOS Host: macOS 27+, Apple Silicon, signed/notarized PKG.
- macOS Client: macOS 15+, Apple Silicon, signed/notarized DMG.

All packages are rebuilt from main on GitHub-hosted builders, not relabeled
candidate artifacts. Verified dependency caches may be reused; application
compilation and packaging run fresh. NVIDIA headers retain the 595.91.07 driver
ceiling. This release does not install or deploy software automatically.

`SHA256SUMS` uses downloadable asset filenames. `manifest.json` records exact
source revisions and package validation with platform-organized catalog paths.
GitHub source archives omit submodules; clone the complete release instead:

```sh
git clone --recurse-submodules --branch v1.0.137 https://github.com/instinctual/plank.git
```

## Validation and limitations

All five release workflows passed at package-source commit
`41cffcddaf487acd84b293fe1792d3406bfe8d64`:

- [Four-product build and Linux packages](https://github.com/instinctual/plank/actions/runs/35362841568).
- [Signed/notarized macOS Host](https://github.com/instinctual/plank/actions/runs/35362882541).
- [Signed/notarized macOS Client](https://github.com/instinctual/plank/actions/runs/35362884456).
- [Clipboard regressions](https://github.com/instinctual/plank/actions/runs/35362841434).
- [Private-information checks](https://github.com/instinctual/plank/actions/runs/35362841435).

The Mac Client passed 156 native Qt test results. Mac Host native pasteboard
tests passed; Linux Xvfb passed 13 backend cases and five negative controls.
Shared clipboard wire validation passed under ASan/UBSan. Local validation
passed seven portable CTest suites, twelve dependency-patch regressions, 43
CI-policy tests and the release-version contract.

Mac signing/notarization/stapling and temporary-key cleanup passed. Linux
dependency, private-runtime, version and package gates passed, including Host
log-directory ownership and Client no-autostart checks. Linux Host performed a
cache-cold dependency bootstrap; all nine required patches were verified during
bootstrap, package preflight and cache sealing. Mac and Linux Client dependency
caches restored and passed independent verification.

No new live hardware tests or installations were performed for this rebuild.
Existing operator acceptance does not replace qualification for every display,
permission, Wacom or network combination.

Immediate paste after a new copy remains a stress-test item: native clipboard
writes are asynchronous and there is no applied-write acknowledgment. Reliable
chunk ordering and retry tests do not establish an atomic copy/paste guarantee.
Clipboard interruption, ownership, reconnect and large-transfer stress remain
part of the qualification matrix.

The existing Linux physical-display lease inconsistency can still reject a
connection with an invalid composite-source/provenance error; this release does
not claim to fix it. macOS 27 beta results require final-OS revalidation.
Remaining unmerged PRs and RK3576 research are excluded.
