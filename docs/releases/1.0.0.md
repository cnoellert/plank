# PLANK 1.0.0

PLANK 1.0.0 is the first stable Linux release of the authenticated remote
workstation system formerly developed under numbered integration builds.

This is an internal-use release. Its packages are unsigned and are published
with SHA-256 sidecars for manual verification. Publication of the unsigned
artifacts was explicitly authorized by the project owner on 2026-09-01.

## Supported deployment

- Rocky Linux 9.7 Host with the qualified proprietary NVIDIA Xorg, NvFBC,
  CUDA, and NVENC stack.
- Ubuntu 26.04 Client using native Wayland, SDL3, Vulkan, PipeWire, and the
  packaged private FFmpeg 9.0.1 runtime.

## Release highlights

- PAM/SSSD authentication with same-account session takeover and no pairing
  database.
- Native single-port KyProto/QUIC transport with RaptorQ recovery, route-aware
  MTU selection, and interactive bitrate control.
- Per-bookmark capture, encoding profile, bitrate, display-layout, and
  presentation configuration.
- Qualified full-range RGB identity workflows, including H.264 High 10 4:4:4
  and HEVC 10-bit 4:4:4 profiles.
- Physical, headless, one-display, and horizontal dual-display workflows with
  safe physical-display restoration.
- Keyboard, absolute mouse, local/remote hybrid cursor, and raw-HID Wacom
  forwarding with pressure, margins, buttons, and custom cursor shapes.
- A Wayland-native streaming toolbar with live statistics, bitrate control,
  minimize, disconnect, pinning, and horizontal movement.
- Administrator-owned Host and Client configuration, boot-managed Host
  services, and no Client autostart.

The exact package hashes, source commits, builder inputs, hardware validation,
and deferred acceptance gates are recorded in `HANDOFF.md`.
